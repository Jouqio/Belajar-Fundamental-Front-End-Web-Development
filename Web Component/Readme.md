## Cara Belajar

Setiap folder modul berisi:
- `README.md` — penjelasan konsep, kenapa penting, dan contoh kode
- `contoh/index.html` — file HTML+JS siap dibuka langsung di browser untuk latihan

Disarankan mengikuti modul secara berurutan dari 1 sampai 20, karena setiap modul membangun pemahaman dari modul sebelumnya.

## Prasyarat

Sebelum belajar Web Component, sebaiknya kamu sudah familiar dengan:
- HTML dasar (tag, atribut, struktur dokumen)
- CSS dasar (selector, styling)
- JavaScript dasar (function, class, event, DOM manipulation)

## Apa yang Akan Kamu Kuasai

Setelah menyelesaikan seluruh modul, kamu akan bisa membuat komponen UI yang **reusable**, **terisolasi (encapsulated)**, dan **framework-agnostic** menggunakan tiga teknologi inti platform web: **Custom Elements**, **Shadow DOM**, dan **HTML Template**.

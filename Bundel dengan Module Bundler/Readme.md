# 📦 Bundel dengan Module Bundler

Modul ini adalah bagian dari kelas **Belajar Fundamental Front-End Web Development**.
Modul ini membahas **module bundler**, khususnya **Webpack**, mulai dari konsep dasar sampai
studi kasus nyata (Club Finder App). Materi ditulis dengan bahasa yang sederhana, disertai
contoh kode yang bisa langsung dicoba, cocok untuk pemula yang baru pertama kali mengenal
build tool di dunia front-end.

##  Tujuan Belajar

Setelah menyelesaikan modul ini, kamu diharapkan mampu:

- Memahami apa itu module bundler dan kenapa dibutuhkan dalam proyek front-end modern.
- Memahami konsep inti Webpack: Entry, Output, Loaders, Plugin, dan Mode.
- Menginstal dan menjalankan Webpack dari nol.
- Membuat dan membaca file konfigurasi `webpack.config.js`.
- Menggunakan Loader untuk memproses file selain JavaScript (CSS, gambar, dll).
- Menggunakan Plugin untuk menambah kemampuan proses build.
- Menjalankan development server dengan `webpack-dev-server`.
- Mengatur konfigurasi berbeda untuk environment development vs production.
- Menerapkan semua konsep di atas pada studi kasus nyata: **Club Finder App**.

##  Cara Belajar yang Disarankan

1. Ikuti urutan folder dari `01` sampai `17`, karena materi disusun bertahap (dari konsep → praktik → studi kasus).
2. Setiap folder punya `README.md` berisi penjelasan konsep + contoh kode.
3. Folder yang punya sub-folder `contoh/` bisa langsung dicoba di komputer kamu:
   ```bash
   cd nama-folder/contoh
   npm install
   npm run build   # atau sesuai instruksi di README masing-masing
   ```
4. Kerjakan **Kuis** di folder `17-Kuis` untuk menguji pemahaman kamu.

##  Prasyarat

- Sudah paham dasar **HTML, CSS, dan JavaScript**.
- Sudah mengenal **Node.js** dan **npm** (kalau belum, install dulu dari [nodejs.org](https://nodejs.org)).

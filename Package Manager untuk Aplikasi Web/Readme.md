## Cara Belajar

Setiap folder modul berisi:
- `README.md` — penjelasan konsep, kenapa penting, dan contoh perintah/kode
- `contoh/` — berkas contoh (`package.json`, script, dsb.) yang bisa langsung dicoba lewat terminal

Disarankan mengikuti modul secara berurutan dari 1 sampai 12, karena setiap modul membangun pemahaman dari modul sebelumnya.

## Prasyarat

- Sudah familiar dengan JavaScript dasar.
- Sudah pernah membuka **terminal / command prompt** (tidak perlu mahir, cukup tahu cara berpindah folder dengan `cd`).

## Apa yang Akan Kamu Kuasai

Setelah menyelesaikan seluruh modul, kamu akan bisa:
- Memasang dan mengelola library pihak ketiga (package) di proyek JavaScript/front-end.
- Memahami isi dan fungsi file `package.json` serta `package-lock.json`.
- Menjalankan script otomatisasi lewat npm (build, test, format, dsb).
- Memahami konsep versioning (Semantic Versioning), dependency vs devDependency, serta scoped package.

## Folder `examples/`
Berisi file HTML+CSS siap-jalan (buka langsung di browser) untuk setiap topik penting, supaya kamu bisa langsung praktik, bukan cuma baca teori.

## Cara Belajar yang Disarankan
1. Baca materi sesuai urutan nomor (0 → 14).
2. Setiap selesai satu topik, buka file contoh di folder `examples/` yang sesuai lalu ubah-ubah sendiri nilainya (misal `grid-template-columns`) dan lihat efeknya langsung.
3. Gunakan DevTools browser (Inspect Element) — Chrome/Firefox punya Grid Inspector bawaan yang sangat membantu.
4. Setelah sampai topik 12 (Studi Kasus), coba layout ulang Club Finder App dari modul HTML Form Lanjutan memakai CSS Grid.
5. Tutup dengan mengerjakan Kuis di file 14 tanpa buka catatan dulu, baru cocokkan jawaban.

Selamat belajar!

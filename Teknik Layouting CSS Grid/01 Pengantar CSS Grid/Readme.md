Modul 1 — Pengantar CSS Grid

Apa itu CSS Grid?
CSS Grid Layout adalah sistem layout 2 dimensi (baris dan kolom sekaligus) yang dibuat khusus untuk mengatur posisi elemen di halaman web. Sebelum ada CSS Grid, developer biasanya memakai float, table, atau flexbox untuk membuat layout — semuanya punya keterbatasan, terutama kalau layout-nya kompleks (misalnya dashboard, galeri foto, atau halaman majalah).

Kenapa CSS Grid penting?

Bisa mengatur baris dan kolom dalam satu sistem (2D), berbeda dengan Flexbox yang cuma 1 dimensi.
Kode lebih ringkas layout rumit bisa dibuat hanya dengan beberapa baris CSS.
Didukung oleh semua browser modern (Chrome, Firefox, Edge, Safari).

# Modul 14: Rangkuman Layouting dengan CSS Grid

## Ringkasan Properti Penting (Container)
| Properti | Fungsi |
|---|---|
| `display: grid` | Mengaktifkan grid |
| `grid-template-columns/rows` | Menentukan struktur kolom/baris |
| `gap` | Jarak antar item |
| `grid-template-areas` | Layout berbasis nama area |
| `justify-items` / `align-items` | Perataan semua item |
| `justify-content` / `align-content` | Perataan seluruh grid |
| `grid-auto-flow` | Arah pengisian item otomatis |

## Ringkasan Properti Penting (Item)
| Properti | Fungsi |
|---|---|
| `grid-column` / `grid-row` | Posisi & ukuran item berdasarkan grid line |
| `grid-area` | Menempatkan item ke area bernama |
| `justify-self` / `align-self` | Perataan item tunggal |

## Alur Belajar yang Sudah Dilalui
1. Memahami konsep dasar & terminologi.
2. Membedakan Grid vs Flexbox.
3. Membuat struktur kolom/baris.
4. Menempatkan & meratakan item.
5. Menggunakan `grid-template-areas` untuk layout halaman utuh.
6. Menerapkan semuanya dalam studi kasus nyata.

## Langkah Selanjutnya
Coba bangun ulang layout dari website favoritmu (misalnya beranda Netflix atau dashboard admin) menggunakan CSS Grid, sebagai latihan mandiri.

Modul 2 — Kenalkan, Saya CSS Grid

Cerita singkat: CSS Grid pertama kali didukung browser secara luas sekitar tahun 2017. Sejak itu, CSS Grid menjadi standar untuk membuat layout halaman modern seperti Netflix, Airbnb, dan hampir semua website besar.

Cara kerja dasar:

Buat elemen pembungkus (parent) → beri display: grid;
Elemen di dalamnya (children) otomatis jadi bagian dari grid.
Atur jumlah kolom dengan grid-template-columns.
Atur jarak antar elemen dengan gap.
